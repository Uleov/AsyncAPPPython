# Задание 4

## Что реализовано
* Асинхронное FastAPI приложение.
* Эндпоинт `GET /ping` для мгновенной проверки работоспособности сервера.
* Эндпоинт `GET /delay/{seconds}` для неблокирующей задержки с валидацией от 0 до 10 секунд.
* Эндпоинт `GET /delay` для передачи задержки и строковой метки label через параметры запроса.
* Фиксация реального времени задержки и передача его в ответе клиенту.

## Требования к окружению
Для запуска веб-приложений необходима установка зависимостей:
```bash
pip install fastapi uvicorn
```

## Как запустить
Запустите сервер из папки задания:
```bash
uvicorn delay_api:app --reload
```

## Примеры запросов (HTTP-клиент)

### 1. Проверка доступности (/ping)
Запрос:
```bash
curl -X GET http://127.0.0.1:8000/ping
```
Ответ:
```json
{"status": "ok"}
```

### 2. Запрос с задержкой в пути (/delay/{seconds})
Запрос:
```bash
curl -X GET http://127.0.0.1:8000/delay/2.5
```
Ответ:
```json
{
  "requested_delay": 2.5,
  "actual_delay": 2.5012
}
```

### 3. Запрос с задержкой и меткой в query (/delay)
Запрос:
```bash
curl -X GET "http://127.0.0.1:8000/delay?seconds=1.5&label=тестовая_метка"
```
Ответ:
```json
{
  "label": "тестовая_метка",
  "requested_delay": 1.5,
  "actual_delay": 1.5008
}
```

### 4. Ошибка валидации (задержка > 10 секунд)
Запрос:
```bash
curl -i -X GET http://127.0.0.1:8000/delay/15
```
Ответ:
```
HTTP/1.1 400 Bad Request
...
{"detail":"Задержка должна быть в диапазоне от 0 до 10 секунд"}
```
