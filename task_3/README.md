# Задание 3

## Что реализовано
* Корутина `producer` для генерации сообщений и отправки маркеров `None` для остановки обработчиков.
* Корутина `consumer` для извлечения сообщений с имитацией задержки и подсчетом количества обработанных элементов.
* Ограничение очереди размером maxsize=5 для демонстрации приостановки отправки (backpressure).
* Применение `queue.task_done()` и `queue.join()` для завершения работы программы.
* Подсчет итоговой статистики обработки сообщений для трех воркеров.

## Как запустить
Запустите программу из терминала:
```bash
python message_queue.py
```

## Какие проверки выполнялись
1. Проверка завершения программы: остановка обработчиков по маркеру None и разблокировка queue.join().
2. Проверка работы лимита очереди: блокировка и возобновление работы продюсера.
3. Проверка корректности подсчета: 15 отправленных сообщений делятся поровну между 3 воркерами.
