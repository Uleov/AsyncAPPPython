# Задание 2: Консольный симулятор загрузок

## Что реализовано
* Корутина `download(url: str, delay: float) -> dict` (симуляция загрузки файла и подсчет размера по длине ссылки).
* Список тестовых ссылок с одной ошибочной ссылкой.
* Режим работы gather с return_exceptions=False: первое исключение прерывает сбор результатов с отменой оставшихся задач.
* Режим работы gather с return_exceptions=True: исключения возвращаются в результатах.

## Как запустить
Запустите программу из терминала:
```bash
python download_simulator.py
```

## Какие проверки выполнялись
1. Проверка конкурентности загрузки: общее время близко к максимальной задержке.
2. Проверка поведения при прерывании (return_exceptions=False): вывод ошибки.
3. Проверка поведения при игнорировании исключений (return_exceptions=True): вывод списка результатов, содержащего как успешные словари, так и объекты ошибок.
