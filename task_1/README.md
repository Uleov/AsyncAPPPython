# Задание 1

## Что реализовано
* Корутина `run_timer(name: str, delay: float)` для запуска таймера с выводом сообщений о старте и финише.
* Последовательный режим выполнения трех таймеров.
* Конкурентный режим выполнения трех таймеров через `asyncio.gather`.
* Измерение времени работы каждого режима.
* Выбор режима через параметр `--mode`.

## Как запустить
Запустите программу из терминала:
```bash
python async_timer.py --mode both
```

Доступные режимы:
* Режим sequential: только последовательный запуск.
* Режим concurrent: только конкурентный запуск.
* Режим both: оба режима по очереди для сравнения времени.

## Какие проверки выполнялись
1. Проверка последовательного режима: программа выполняется примерно 4.5 секунды.
2. Проверка конкурентного режима: программа выполняется примерно за 2.0 секунды (по максимальной задержке).
3. Проверка некорректного режима запуска (валидация аргументов).
